Yappari JS help

Yet Another Program for Analysis and Research in Impedance: one equivalent circuit fitted to one or to thousands of impedance spectra, in the browser.

Getting started

  1. Read data with File (Auto detects the format) or drop files on the window. New datasets appear at the top of the Datasets list. To try the program, use File, Load 24 demo spectra.
  2. Build a circuit in the Model tab: click elements in the palette, insert a template, or type a circuit code such as R(RQ)(RQ) and press Enter.
  3. Set start values in the Parameters side panel: type a value, or turn the mouse wheel over a parameter. Tick fit for the parameters to fit.
  4. Fit: click Fit in the top bar or press F9. Several selected datasets are fitted in parallel, each on its own; switch the mode to Global (Fit side panel) for one fit with shared parameters.
  5. Many spectra: fit one, copy its values to all datasets (Parameters panel, Copy these values to: All datasets), select all with Ctrl+A in the list and fit.
  6. Save parameters, data, a report or the whole project from the File menu (Ctrl+S saves the project).

Not sure which circuit to use? Analysis, Search models fits a catalogue of circuits to one spectrum and ranks them.

Running it: web server or local file

Yappari JS is a set of static files (index.html, js/, catalog/, config/). Fits run in Web Workers built inside the page, so most of the program also works when index.html is opened directly from disk.

Model search and preset definitions need a web server. Browsers do not let a page opened from disk (file://) read other local files, so the circuit catalogue (catalog/models_*_elements.txt), the prior file (catalog/priors.txt) and the XML presets (config/definitions/) cannot be loaded that way: Search models stops with “Failed to fetch”, and File, Auto and Custom format use only the built-in readers.

Any static web server works. For a local copy, run in the program folder:

python -m http.server 8000

then open http://localhost:8000. On a public server (GitHub Pages, an institute web space) nothing else is needed.

Datasets

The Datasets side panel lists the spectra, newest first. Click to select, Ctrl+click to add one, Shift+click for a range, Ctrl+A for all; arrows move the selection. Double-click or F2 renames, Delete deletes, drag a row to reorder. The dot on the right shows the fit state: green converged, amber a warning (iteration limit, stalled, singular, at limits), red failed. Commands act on the selected datasets.

Each dataset keeps its own parameter values for the one circuit; limits and the shared flags of the global fit are common to all.

Plots

The EIS tab shows Nyquist, Zr and Zi versus frequency (with residuals), |Z| and phase, and a 3D view of many spectra. Measured points are drawn as markers (masked points hollow), the model as lines. Drag to zoom, Shift-drag or right-drag to pan, wheel to zoom, double-click to autoscale. Click a legend entry to hide or show it. Save PNG saves the plot on screen.

On the Nyquist plot: Label frequency marks the point nearest to a frequency (1k, 2.5M, 10m are accepted), Click labels a point labels by clicking, Square gives a square frame. Show contributions (Model tab) draws each part of the series chain in its own colour as dashed curves, and colours the circuit drawing the same way.

Settings choose absolute or relative residuals, degrees or radians, equal Nyquist axes, and how many datasets are drawn at most (larger selections are thinned out for drawing only).

Circuits: the circuit code

A circuit is written as a Boukamp circuit description code. Elements written next to each other are in series; round brackets put their content in parallel; square brackets put their content in series inside a parallel group.

CodeCircuit
R(RQ)Rs + (R ‖ Q): one depressed semicircle
R(Q[RW])Randles: Rs + Q ‖ (Rct + W)
R(RQ)(RQ)Rs + two R ‖ Q in series (Voigt)
R(Q[R(RQ)])ladder: Rs + Q ‖ (R + R ‖ Q), e.g. a coating over a corroding metal

Numbers name the elements (R1, Q2) and are added for you; they keep parameter names stable when the circuit is edited, so values of elements that remain are kept. Spaces, commas, dashes and plus signs between elements are ignored.

In the Model tab, click an element of the drawing to select it, choose In series, In parallel or Replace, and click an element of the palette. Delete removes the selection, Undo last action goes back, Clear empties the circuit. The template list inserts common circuits. The circuit cannot change while a fit runs.

Elements

ω = 2πf. Parameter names are the element name plus the suffix shown (Q1, Q1_n, Wo1_A, Wo1_B …). Defaults below are the built-in start values and limits; Settings, Start values for new elements changes them.

Parameters and limits

The Parameters side panel shows the values of the first selected dataset (← → show the others of the selection); an edit applies to all selected datasets. Mouse wheel or arrow keys change a value: ×1.02 per step for parameters that span decades, ±0.005 for n, α, β; Shift for larger steps, Alt or Ctrl for finer ones. The tick on the right decides whether a parameter is fitted. After a fit, the standard error is shown next to the value (see statistics).

Limits (Settings, Parameter limits for the current circuit) are common to all datasets; bounded methods keep every parameter between them. The same table holds the shared flag of each parameter for the global fit. Limit edits, shared flags and renames can be undone like any other change.

Copy these values to copies the values and fit ticks of the first selected dataset to all datasets or to the other selected ones.

Fitting

The fit minimises the weighted sum of squares of the real and imaginary residuals:

χ²w = Σk wk [(Zrcalc − Zr)² + (Zicalc − Zi)²]

WeightwkUse
1/|Z|1/|Zk|default; a compromise between equal and relative weights
1/|Z|²1/|Zk|²relative errors; matches noise proportional to |Z|
11absolute errors; dominated by the largest |Z|
measured σ1/σ² for each partSettings, Use measured standard deviations, when the file has them; points without one get the median relative error of the others
Method
Trust-region dogleg, boundeddefault; robust with limits
Levenberg–Marquardt, boundedclassical, with limits
Levenberg–Marquardt, no boundsignores the limits
Nelder–Mead, boundedderivative-free simplex; slower, useful from poor start values

Parameters that span decades (R, C, L, Q, Aw, B, τ) are fitted as ln p, which keeps them positive and handles values from 10⁻¹² to 10⁹ alike. Max iterations (1 to 65535) and Min χ² step (relative change between iterations) end the fit. A fit that ends with tiny steps is checked with one more Gauss–Newton step: if χ² can still decrease, it is reported as stalled rather than converged.

Messages starting with converged are normal ends. Iteration limit reached, stopped: no further progress, singular system and all fitted parameters are at their limits are warnings. Stop (Fit side panel, shown while a fit runs) ends a batch at once; datasets not yet fitted keep their values.

Global fit

Mode Global (Fit side panel) fits all selected datasets at once. Parameters ticked shared get one value for all datasets; the others one value per dataset. The fit ticks and the start values of shared parameters come from the dataset shown in the Parameters panel. In Global mode a padlock next to each parameter switches shared and local. The global fit uses Levenberg–Marquardt (bounded unless the method is the unbounded one) with a Schur complement on the shared block, so hundreds of datasets with local parameters stay fast.

Fit statistics

ValueDefinition
χ²wthe minimised weighted sum of squares
χ²redχ²w / (2N − p): N frequencies, real and imaginary parts both counted, p fitted parameters; about 1 when σ weights are right
R²1 − SSres/SStot on the stacked, unweighted (Zr, Zi) values (written R^2 in parameter files)
SE %standard error in % of the value, from s² (JᵀJ)⁻¹ with s² = χ²red and the Jacobian J of the weighted residuals at the solution. Parameters on a limit get no SE.
An SE above about 30 % means the data determine the parameter poorly: the ± interval is then only indicative (for a series resistance the true spread is close to symmetric, for a capacitance closer to a factor). Consider fixing the parameter, a simpler circuit, or more frequencies.

Distribution of relaxation times (DRT tab)

Z(ω) = R∞ + Rpol ∫ g(τ) / (1 + jωτ) d ln τ, ∫ g d ln τ = 1

R∞ is fitted with the distribution, Rpol is the area of g. Methods: Tikhonov with non-negativity (regularisation λ), Fisk (iterated Tikhonov), Gold (multiplicative deconvolution; fewer iterations = smoother). The data can be Zr and Zi, Zi only or Zr only; masked points are used. Search λ scans the regularisation and suggests the strongest one whose misfit stays within 10 % of the best. Views: the distribution, the rebuilt spectrum, the residuals and the peaks (R, τ, f, C = τ/R and share of Rpol of each peak). Save DRT writes distributions, spectra and peaks of all selected datasets.

Z-HIT and Kramers–Kronig test (Analysis menu)

Z-HIT rebuilds ln|Z| from the phase (integral plus derivative corrections); the measured |Z| should match it. Deviations point to drift or artefacts, but can also reflect noise, the ends of the range or sharp resonances. New datasets zh_… hold the rebuilt values. A range needs at least 10 points and two decades; gaps split the data into ranges checked separately.

Kramers–Kronig test (Lin-KK, Boukamp; Schönleber et al.) fits a chain of RC elements with log-spaced time constants, which obeys the Kramers–Kronig relations, and reports the residuals in % of |Z|. The number of RC elements is chosen where more stop improving the fit (or given with the command kk>>M). Residuals above the noise, or with a trend, point to drift, non-linearity or artefacts. New datasets kk_… hold the fit.

Model search

Analysis, Search models fits every circuit of a catalogue to the selected dataset (one dataset, Individual fit mode) and ranks them. It needs a web server.

Catalogue

catalog/models_N_elements.txt list all series/parallel topologies with N elements, without duplicates by order or grouping and without directly repeated R, C, L or W (which reduce to one). They are written by script/generate_models.py; the default files use R, C, L, Q, W, and the script can include Wo, Ws, G and HN. The counts grow fast (R, C, L, Q, W: 1106 circuits with 4 elements, 9632 with 5, 89 670 with 6, 873 588 with 7), so restrict the elements and the size: the time is roughly the number of circuits × starts.

Start values are drawn so that every element is visible in the measured window: a random frequency inside the data range and a random |Z| around the measured ones (n of Q between 0.6 and 1). Starts run in rounds of 4; a circuit stops early once two starts reach the same minimum.

Bayesian ranking

Circuits are ranked by their posterior probability given the spectrum D:

P(M | D) ∝ P(D | M) · P(M)

P(M), the prior of the circuit, is its weight in catalog/priors.txt: circuits used in the literature get more weight than the many unlisted topologies.

P(D | M), the evidence, integrates the fit over the prior of the parameters. It is computed with the Laplace approximation at the fitted optimum θ* (coordinates ln p for R, C, L, Q, Aw, B, τ; p for n, α, β):

ln P(D | M) ≈ ln L(θ*) + ln π(θ*) + (k/2) ln 2π − ½ ln det(JᵀJ / s² + Σπ−1)

With measured σ, ln L = −χ²/2. Otherwise the common noise scale is integrated out: ln L = −N ln χ²w (N frequencies, 2N values), with s² = χ²w/2N. The parameter priors π are scaled to the data: a resistance between |Z|min/30 and 10 |Z|max, a capacitance whose impedance falls in that range inside the measured frequencies, and so on, as a log-normal spanning ± 2 standard deviations over that range; n of a CPE has a normal prior around 0.85.

The result works as an Occam factor: a parameter sharply determined by the data costs the ratio of its prior width to its posterior width, a parameter the data do not determine costs little but gains nothing, and an element that does not improve the fit lowers the evidence. Unlike BIC, the penalty depends on how well each parameter is determined, not only on how many there are.

Read P % as a ranking among the circuits searched, not as an absolute probability: it depends on the catalogue (another catalogue changes the normalisation), on the priors, and on the Laplace approximation, which is rough for parameters sitting on a limit or very poorly determined. A circuit that cannot be told apart from another on the data is merged with it; choose between them on physical grounds.

The prior file: catalog/priors.txt

A text file next to the catalogue, read when a search starts; edit it with any text editor (fields separated by a TAB or two or more spaces; # starts a comment). Without it, every circuit gets the same prior.

default  0.5
circuit  R(C[RW])  10   Randles (literature and reviews)
circuit  R(RQ)     5
circuit  LR(RQ)    0    weight 0 excludes a circuit
param    *         window  2
param    Q_n       normal  0.85  0.15
LineMeaning
default wprior weight of every circuit not listed
circuit code w [comment]relative weight of a circuit. Element numbers, order, grouping and directly repeated R, C, L, W do not matter: R(RQ), (QR)R and R1(Q1R2) are the same entry. ln w is added to the log evidence: weight 10 against the default 0.5 is a factor 20.
param name window klog-normal prior of a decade-spanning parameter, centred on the range the data can show, which spans ± k standard deviations (* = all of them)
param name normal mean sdnormal prior of n, α or β

Parameter names: R, C, L, Q, Q_n, W, Wo_A, Wo_B, Ws_A, Ws_B, G_R, G_tau, HN_R, HN_tau, HN_a, HN_b. Lines that cannot be read are reported in the status line of the search and skipped.

The shipped draft weights each circuit as 1 + its occurrences in the literature list of Van Haeverbeke et al. (circuits from published studies in seven domains, with their DOIs in the comments) + 2 × the reviews and benchmarks that present it as a standard model (Lazanas & Prodromidis; Gamry; Zhang et al.; Schaeffer, Gasper et al.). Adapt it to your field: raise the circuits your community uses, set 0 for those that make no physical sense for your system.

Undo and Log

Before every action that changes datasets, the circuit, limits or shared flags, a restore point is kept (up to 256 MB; unchanged data are stored once). Data, Undo the last command (or the command undo, or Ctrl+Z in the circuit drawing) goes back one step; repeat to go further. The Log tab lists every message, with a Restore before button on each action still kept: it brings back the datasets, the selection and the circuit as they were just before, and can itself be undone.

Settings

The Settings button (top right) opens fit settings (method, weights, iterations, tolerance), data settings (column separator, measured standard deviations), simulation range and points, plot settings, the parameter limits and shared flags of the current circuit, and the start values and limits used for new elements. Settings are stored in this browser; Save settings writes them to a file. The switch next to it chooses a light or dark theme.
