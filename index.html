    Yappari JS

    Yet Another Program for Analysis and Research in Impedance. One equivalent circuit is fitted to one or to thousands of impedance spectra. Browser version of Yappari 5.1 (LabVIEW) by Nita Dragoe, Université Paris-Saclay, ICMMO.

    Working with it

    1. File, read data, or drop files on the window. New datasets appear at the top of the list.
    2. Build the circuit in the Model tab by clicking elements, or type a circuit code.
    3. Select a dataset, set start values (mouse wheel over a parameter), tick the parameters to fit, then click Fit in the top bar (or press F9). Switch the mode to Global for one fit with shared parameters.
    4. For many spectra: in Parameters, copy the values to all datasets; select all with Ctrl+A in the list; click Fit in the top bar.
    5. Save parameters, data, a report or the whole project from the File menu.

    Circuit code

    Elements written next to each other are in series. Round brackets put their content in parallel, square brackets put their content in series inside a parallel group. R(RQ)(Q[RW]) is Rs + (R‖Q) + (Q‖(R + W)). Elements: R, C, L, Q (constant phase element), W, Wo, Ws (Warburg), G (Gerischer), HN (Havriliak–Negami). Numbers name the elements (R1, Q2) and are added for you.

    Checks and relaxation times

    The DRT tab shows the distribution of relaxation times of the selected datasets (Tikhonov with non-negativity, Fisk or Gold; R∞ and Rpol from the data), with peak estimates of R and C. Analysis, Z-HIT checks a spectrum: |Z| rebuilt from the phase should match the measured |Z|. Analysis, Kramers–Kronig test fits a chain of RC elements that obeys the Kramers–Kronig relations (Lin-KK) and gives the residuals: above the noise level they point to drift or non-linearity. Show contributions, in the Model tab, colours each part of the series chain, on the plots and in the circuit drawing.
